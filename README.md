# DoseLine PWA — محاسبه‌گر بالینی دوز و قطره‌شمار میکروست

نسخه‌ی کاملاً سمت‌کلاینت (بدون سرور) — دقیقاً مثل الگوی اپ ABG قبلی روی
GitHub Pages، قابل نصب روی گوشی از طریق مرورگر.

## انتشار روی GitHub Pages (همون روشی که برای ABG استفاده کردی)

1. یه ریپوی جدید بساز (یا از همون ریپوی abg-app یه پوشه‌ی جدا بساز)
2. همه‌ی فایل‌های این پوشه (`index.html`, `manifest.json`, `sw.js`, `css/`, `js/`, `icons/`) رو داخل ریپو push کن
3. تنظیمات ریپو → Pages → Source رو روی شاخه‌ی اصلی (main) بذار
4. لینک `https://<username>.github.io/<repo-name>/` باز می‌شه
5. توی مرورگر گوشی (Chrome/Safari) بازش کن → گزینه‌ی «Add to Home Screen» / «نصب» رو بزن

## تست محلی قبل از انتشار

```bash
cd med-dose-pwa
python3 -m http.server 8000
```
بعد باز کن: http://localhost:8000

## نکات فنی مهم

- **بدون بک‌اند**: تمام منطق (دیتای دارو + موتور محاسبه) به جاوااسکریپت پورت
  شده (`js/data.js` و `js/calc.js`) — همون منطقی که در نسخه‌ی Flask تست شده،
  عیناً اینجا هم تست و تأیید شده (نتایج محاسبات هر دو نسخه دقیقاً یکسانه).
- **آفلاین کار می‌کنه**: `sw.js` بعد از اولین بار باز کردن، همه‌ی فایل‌ها رو
  کش می‌کنه — یعنی حتی بدون اینترنت (مثلاً توی بخش با آنتن ضعیف) کار می‌کنه.
- **مسیریابی**: از هش-روتینگ (`#/`, `#/category/x`, `#/drug/1`) استفاده شده،
  چون GitHub Pages روتینگ سمت‌سرور نداره.
- **اگه داروی جدید اضافه کردی**: فقط کافیه `js/data.js` رو ویرایش کنی — اگه
  نسخه‌ی Flask (`med-dose-app`) رو هم داری و می‌خوای هماهنگ بمونن، دوباره از
  `database.py` اکسپورت بگیر (دستورش تو کد قبلی هست) و `data.js` رو بازسازی کن.

## ⚠️ همون هشدار همیشگی

هر عدد در `js/data.js` باید قبل از استفاده‌ی بالینی واقعی توسط داروساز/پزشک و
طبق پروتکل بیمارستانت تأیید بشه. این یک ابزار مرجع آموزشی‌ست.
